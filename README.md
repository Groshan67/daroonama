# دارونما

پایگاه داده فارسی و راست‌چین قیمت دارو؛ الهام‌گرفته از ساختار YakkaLab و بازطراحی‌شده برای بازار ایران.

دیتابیس واقعی ۵۲٬۲۰۵ رکوردی، جستجوی فارسی، مقایسه محصولات هم‌ماده، نمودار روند قیمت، شبیه‌سازی هزینه روی داده واقعی و لیست پیگیری.

> این پروژه نمونه آموزشی است. قیمت‌ها و آمار آن واقعی نیستند و جایگزین فهرست رسمی، مشاوره داروساز یا پزشک محسوب نمی‌شوند.

## امکانات

- **خانه**: آمار واقعی دیتابیس، جستجوی سریع با پیشنهاد زنده، رتبه‌بندی قیمت و سازندگان، دسته‌بندی ATC و مواد مؤثره پرتکرار.
- **جستجو**: جستجو بر اساس نام محصول، ماده مؤثره، شرکت، کد IRC یا ATC با فیلتر دسته، نوع دارو/مکمل، قیمت و شکل دارویی.
- **صفحه دارو**: قیمت بسته و هر واحد، تاریخچه مشاهده‌های واقعی، مقایسه هم‌ماده، مسیر ATC، IRCهای متصل و مشخصات.
- **ماده مؤثره / دسته / سازنده**: فهرست‌های واقعی برای مرور و رفتن به نتایج جستجو.
- **شبیه‌سازی هزینه واقعی**: انتخاب دارو از دیتابیس، قیمت بسته واقعی، تعداد بسته، افق و نرخ رشد.
- **ابزارهای نمایشی**: تقویم بازنگری ۱۴۰۵، آرشیو و جستجوی شرطی با خروجی CSV.
- **دستیار داده (بتا)**: پاسخ‌دهی قاعده‌محور با اتصال مستقیم به دیتابیس واقعی؛ بدون اتصال به مدل زبانی بیرونی.
- **لیست پیگیری**: ذخیره در `localStorage`، نمایش تغییر قیمت از زمان افزودن و پشتیبانی از کلید `F` در صفحه دارو.
- **ورود داده واقعی CSV**: بارگذاری خروجی هفتگی سازمان غذا و دارو، تحلیل ستون‌ها، نگاشت خودکار، ثبت در SQLite و ساخت تاریخچه قیمت بر اساس IRC.
- **کاوش داده‌های واردشده**: جستجو، دسته‌بندی، نوع دارو/مکمل، جزئیات محصول و نمودار تاریخچه قیمت روی داده واقعی.
- **سلسله‌مراتب ATC**: درج پنج سطح ATC از فایل رسمی، مرور درختی و اتصال محصول به مسیر ATC.
- **RTL کامل**، فونت Vazirmatn، ریسپانسیو و سازگار با موبایل.

## اجرا

نیازمند **Node.js 22.5 یا جدیدتر** است (به‌دلیل `node:sqlite`).

```bash
pnpm install
pnpm dev       # http://localhost:3100
pnpm build
pnpm start     # http://localhost:3100
```

## صفحه‌های اصلی

- `/ingredients` → مرور زنده ۱٬۷۲۹ ماده مؤثره با حروف الفبا
- `/ingredient/[slug]` → محصولات ماده، آمار و نمودار روند قیمت
- `/categories` → مودال دسته‌بندی ATC
- `/category/[code]` → مواد و محصولات یک دسته
- `/companies` → کارت‌های صاحبان برند/تولیدکنندگان
- `/company/[id]` → آمار و محصولات شرکت با تفکیک نقش
- `/drug/[irc]` → صفحه محصول، قیمت بسته/واحد، تاریخچه، ATC و مقایسه‌ها
- `/simulation` → شبیه‌سازی هزینه روی قیمت بسته واقعی

## داده‌ها

- دیتابیس واقعی: ۵۲٬۲۰۵ رکورد خام، ۴۴٬۶۰۵ محصول جاری، ۱٬۷۲۹ ماده مؤثره، ۲٬۴۶۱ صاحب برند و ۶٬۹۹۶ کد ATC.
- ۷٬۶۰۰ IRC قدیمی/تکراری به محصول جاری متصل شده‌اند و از نتایج جستجو پنهان می‌شوند.
- ۲۱٬۹۳۶ محصول جاری قیمت دارند؛ ۲۲٬۶۶۹ محصول (از جمله مکمل‌ها) بدون قیمت هستند.
- داده نمونه (`lib/data`) فقط برای تقویم، آرشیو و جستجوی شرطی باقی مانده است؛ خانه، جستجو، صفحه دارو، مواد مؤثره، دسته‌ها، شرکت‌ها، شبیه‌سازی و دستیار روی SQLite اجرا می‌شوند.
- تولید داده نمونه قطعی است تا صفحات نمایشی تغییر نکنند.

## هویت محصول

`IRC` در طول زمان پایدار نیست؛ ممکن است همان محصول با IRC جدید و قیمت جدید ثبت شود. بنابراین:

- `product_identity` هویت پایدار محصول را نگه می‌دارد.
- `identity_alias` همه IRCهای متصل را ذخیره می‌کند.
- `identity_price_history` یک مشاهده قیمت به‌ازای هر هویت و تاریخ دارد.
- محصول برنددار با `GenericCode + صاحب برند + برند + دوز + شکل + مسیر + بسته` تطبیق داده می‌شود؛ در محصول بدون برند، GTIN مبناست.
- IRC قدیمی در `/drug/[irc]` به محصول جاری redirect می‌شود.
- اگر فایل جدید قیمت نداشته باشد، آخرین قیمت معتبر حفظ می‌شود و پرچم «قیمت جدید نیامده» می‌خورد.

## قیمت

`ConsumerPrice` در فایل، **قیمت هر واحد** است:

```text
قیمت بسته = ConsumerPrice × PackageCount
قیمت واحد = ConsumerPrice
```

- برای `PackageCount = 0` قیمت بسته «نامشخص» است و فقط قیمت واحد (در صورت وجود) نمایش داده می‌شود.
- قیمت خالی/صفر به «نامشخص» تبدیل می‌شود.
- همه صفحه‌های خانه، جستجو، ماده مؤثره، دسته، شرکت و دارو از همین دو قیمت استفاده می‌کنند.

## ورود داده واقعی CSV

1. به `/import` بروید.
2. فایل CSV را انتخاب کنید (واحد قیمت را در صورت نیاز «ریال» یا «تومان» بگذارید).
3. «تحلیل فایل» را بزنید و ستون‌های شناسایی‌شده، کیفیت داده و نمونه‌ها را ببینید.
4. «ثبت در دیتابیس» را بزنید.
5. برای کاوش، `/imported` را باز کنید.

دیتابیس در `.data/daranama.sqlite` ذخیره می‌شود. هر ورود یک `import_batch` می‌سازد و قیمت هر IRC در `price_history` ثبت می‌شود؛ بنابراین با ورود هفتگی، تاریخچه قیمت ساخته می‌شود.

نسخه فعلی شامل فایل کامل `A14050727.csv` با **۵۲٬۲۰۵ رکورد** (۴۴٬۶۰۵ محصول جاری)، دو فایل هفتگی آتوموکستین و ۶٬۹۹۶ کد ATC است. ۲۱٬۹۳۶ محصول جاری قیمت دارند و ۲۲٬۶۶۹ محصول (از جمله همه مکمل‌ها) بدون قیمت هستند. برای شروع از صفر، فایل `.data/daranama.sqlite` را حذف کنید و سرور را دوباره اجرا کنید.

### همگام‌سازی DrugIndex رسمی

```bash
pnpm sync:drugindex
```

این اسکریپت سرویس `GetAllDrugIndexesWithSpecificAttribute` را صفحه‌به‌صفحه می‌خواند و در جدول‌های `drug_indexes` و `drug_index_ingredients` درج می‌کند. ارتباط از طریق `products.drug_index_id = drug_indexes.id` حفظ می‌شود.

- خروجی فعلی: ۳٬۱۷۴ رکورد و ۴٬۱۶۰ ماده.
- `Count` سرویس ۴٬۵۶۴ اعلام می‌شود، ولی صفحه‌های بعد از ۳٬۱۷۴ خالی‌اند؛ اسکریپت داده واقعی برگشتی را درج می‌کند و هشدار می‌دهد.
- از `RialPriceCeiling` استفاده نمی‌کنیم.
- اطلاعات رسمی در صفحه دارو نمایش داده می‌شود: نام رسمی، تاریخ ثبت، OTC/بیمارستانی، بیولوژیک، مواد ترکیب و وضعیت لغو.

### ورود سلسله‌مراتب ATC

```bash
node scripts/import-atc.mjs "C:\path\to\atc.csv"
```

اسکریپت کدها را بر اساس طول به پنج سطح ATC تقسیم می‌کند، `parent_code` و مسیر کامل را می‌سازد و در یک تراکنش در جدول `atc_nodes` درج می‌کند. فایل کامل فعلی ۶٬۹۹۶ کد دارد و در دیتابیس درج شده است؛ ۲٬۲۷۲ محصول کد ATC‌شان در این فایل نیست.

تحلیل کامل فیلدها، انتخاب Ingredient و شرکت، قواعد یکتاسازی، نتیجه مقایسه دو فایل هفتگی و ساختار ATC در [DATA-MAPPING.md](./DATA-MAPPING.md) آمده است.

## دسترسی مدیر

بخش «داده» در منو فقط برای مدیر نمایش داده می‌شود. این مسیرها محافظت‌شده‌اند:

```text
/import
/imported
/atc
/api/import/*
```

ورود از `/login` انجام می‌شود. تنظیمات در `.env.local`:

```env
ADMIN_USERNAME=admin
ADMIN_PASSWORD=change-this-password
AUTH_SECRET=replace-with-a-random-64-character-secret
```

- نشست با کوکی `HttpOnly` و امضای HMAC ذخیره می‌شود.
- درخواست‌های API بدون نشست معتبر `401` می‌گیرند.
- تلاش‌های ناموفق ورود محدود می‌شوند.
- خروج مدیر از فوتر یا `/api/auth/logout` انجام می‌شود.
- `.env.local` نباید commit شود؛ [.env.example](./.env.example) فقط نمونه است.

## سئو

- دامنه canonical و OpenGraph: `https://groshan.ir`
- عنوان و توضیح فارسی با کلیدواژه‌های اصلی قیمت دارو، IRC، ژنریک، ATC و ماده مؤثره
- `metadata` اختصاصی برای صفحه دارو، ماده مؤثره، شرکت و دسته ATC
- OpenGraph image در `/og-groshan.png`
- `sitemap.xml` واقعی شامل ۴۹٬۰۲۵ URL: محصولات، مواد مؤثره، شرکت‌ها و دسته‌ها
- `robots.txt` با مسدودکردن `/api`، `/login`، `/import`، `/imported` و `/atc`
- JSON-LD شامل `WebSite`، `Organization` و `Dataset`
- `manifest.webmanifest` برای PWA

بعد از استقرار، `https://groshan.ir/sitemap.xml` را در Google Search Console ثبت کنید.

## ساخت خروجی standalone

```bash
pnpm build
```

خروجی در `.next/standalone` ساخته می‌شود و شامل `server.js`، وابستگی‌های runtime و فایل دیتابیس است. برای استقرار:

```bash
tar -xzf groshan-standalone.tar.gz -C /path/to/groshan
cd /path/to/groshan
PORT=3000 HOSTNAME=0.0.0.0 node server.js
```

فایل `DEPLOY.md` داخل آرشیو، تنظیمات Nginx، متغیرهای محیطی و نکات Search Console را توضیح می‌دهد.

## محدودیت‌ها

- داده زنده یا همگام‌سازی خودکار با سامانه رسمی ندارد؛ ورود CSV دستی است.
- همه مکمل‌ها در فایل منبع قیمت و تعداد بسته ندارند.
- ۲٬۲۷۲ محصول کد ATC خارج از درخت ATC فعلی دارند و مسیر ATC برایشان نمایش داده نمی‌شود.
- تقویم، آرشیو و جستجوی شرطی هنوز روی داده نمونه کار می‌کنند؛ شبیه‌سازی و دستیار واقعی‌اند.
- دستیار هوشمند به مدل زبانی متصل نیست و پاسخ‌ها از قواعد و داده‌های محلی ساخته می‌شوند.
- لیست پیگیری فقط در مرورگر ذخیره می‌شود و بین دستگاه‌ها همگام نمی‌شود.
- هشدار قیمت به‌صورت ایمیل/پیامک ارسال نمی‌شود.

مشخصات کامل پیاده‌سازی در [SPEC.md](./SPEC.md) آمده است.
